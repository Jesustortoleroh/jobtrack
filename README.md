# JobTrack — Job Application Tracker

A full-stack web application that gives job seekers one place to organize their search: save opportunities, move applications through a visual board, associate resume versions, track contacts, notes, interviews, and follow-ups.

## Team Members
- Roger Galan

## Tech Stack
- **Front end:** Svelte, JavaScript, HTML, CSS
- **Back end:** Node.js, Express
- **Database:** MongoDB (Mongoose)
- **API:** REST + JSON
- **Auth:** JWT with hashed passwords
- **Tools:** Git/GitHub, npm, ESLint, Prettier, Postman/Bruno
- **Deployment:** Static front-end host + Node API host + MongoDB Atlas
